# 11 — Glossary (English · العربي)

Use these terms in code, UI copy and docs. Arabic column = Egyptian merchant usage for UI copy.

| Term | العربي | Meaning |
| --- | --- | --- |
| COD (cash on delivery) | الدفع عند الاستلام · كاش | Customer pays the courier on delivery |
| Prepaid | مدفوع مقدماً | Paid online before shipping |
| Order | أوردر · طلب | A customer purchase from a store |
| Confirmation | تأكيد الأوردر | Checking with the customer that the order is real before shipping |
| Confirmation agent | موظف التأكيد · الكول سنتر | Person who calls or messages customers |
| Risk score | درجة الخطورة | 0–100 likelihood an order is fake or will be refused |
| Fake order | أوردر وهمي | Order with no real intent to buy |
| Duplicate order | أوردر مكرر | Same customer + product within the window |
| Shipment | شحنة | Parcel booked with a courier |
| Courier | شركة الشحن | Bosta, J&T, Aramex … |
| Tracking number | رقم البوليصة · رقم التتبع | Courier's shipment ID |
| Airway bill / label | البوليصة | Printed shipping label |
| Pickup | البيك أب | Courier collects parcels from the warehouse |
| Failed attempt | محاولة فاشلة | Courier could not deliver this time |
| RTO (return to origin) | مرتجع · رفض الاستلام | Parcel refused or undeliverable, returned to merchant |
| Return | مرتجع | Customer sends an item back after delivery |
| Exchange | استبدال | Return + new linked order |
| Open-box delivery | المعاينة | Customer inspects before paying; may refuse part |
| Partial delivery | تسليم جزئي | Customer keeps some items, returns others |
| Inspection | فحص المرتجع | Restock, damaged or write-off decision |
| Settlement | التسوية · تحويل الكاش | Courier transfers collected COD cash minus fees |
| Cash in transit | كاش عند شركة الشحن | Collected by courier, not yet settled |
| COGS | تكلفة البضاعة | Cost of the goods sold |
| Net profit per order | صافي الربح للأوردر | Revenue minus all costs for that order |
| Delivered rate | نسبة التسليم | Delivered ÷ shipped |
| Delivered ROAS | العائد على الإعلانات من الأوردرات المستلمة | Delivered revenue ÷ ad spend |
| CAPI | Conversions API | Server-side events sent to ad platforms |
| SKU | كود المنتج | Stock-keeping unit (variant code) |
| Reserved stock | مخزون محجوز | Held for confirmed, unpacked orders |
| Available stock | المخزون المتاح | On hand − reserved |
| Oversell | بيع أكتر من المخزون | Selling stock you do not have |
| Pick / pack | التجهيز / التغليف | Collect items / pack the parcel |
| Governorate | المحافظة | Egyptian province |
| Location pin | لوكيشن | Map location sent by the customer on WhatsApp |
| Template (WhatsApp) | تمبلت | Pre-approved WhatsApp message |
| 24-hour window | نافذة الـ 24 ساعة | Free reply period after a customer message |
| Opt-in | موافقة العميل | Customer agreed to receive messages |
| Dialect | اللهجة | Egyptian, Gulf, Darija, Levantine, Iraqi |
| Recipe (automation) | وصفة أتمتة | Ready-made When → If → Then rule |
| Tenant | الحساب · البيزنس | One merchant account in Mizan |
| Connection | الربط | A connected store, courier or channel |
| Drift | تغيير في الـ API | Provider payload changed from what the adapter expects |
| Dead letter | مهمة متوقفة | Job that needs a person to fix and replay |
| Outbox | طابور المهام | Durable queue of external writes |
| Idempotency key | مفتاح عدم التكرار | Key that makes a repeated request safe |
| Canonical model | النموذج الموحد | Mizan's provider-neutral data shapes |
| ZATCA | هيئة الزكاة والضريبة | Saudi tax authority (e-invoicing) |
| ETA | مصلحة الضرائب المصرية | Egyptian Tax Authority (e-receipt) |
| PDPL | نظام حماية البيانات الشخصية | Saudi personal data protection law |
| Law 151/2020 | قانون حماية البيانات الشخصية | Egyptian data protection law |
