01

A type-only mark with one red point

The wordmark is set in Geist Bold, the Arabic in Alexandria Bold, both converted to outlines. The dot of the i and the dot of the ن turn Brandita red: the same rule as Brandita's own mark, black with a red dot.

✓Clear space of at least the height of the m on every side.
✓Minimum size: 72 px wide on screen, 18 mm in print. Below that, use the m. monogram.
✓Colour: ink with a red point on paper, white with a red point on ink, or one-colour when the medium demands it.
✕Never set the logo in live type, recolour it, outline it, rotate it or add a shadow.
✕Never move the red point or add a second red element to the mark.
✕Never place it on a busy image without a solid ink or paper ground.
02

Brandita's palette, with red kept for meaning

Primary actions are ink. Red marks the brand point, the active indicator, the one number that matters, and errors. If a screen shows red in four places, three of them are wrong.

Geist for Latin, Alexandria for Arabic

04

@@ICONCOUNT@@ icons named after the product

Built on Lucide, 1.75 stroke on a 24 grid. Names describe meaning (cod, refund, verification), not shape, so a glyph can change without touching the app. Icons marked ⇄ mirror in Arabic.

05

Flat, precise components

No shadows on cards or buttons, as in Brandita's identity; only floating layers (menus, dialogs) cast one. Every rule uses logical properties, so Arabic layouts mirror with no extra code.
